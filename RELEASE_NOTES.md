## 🔒 Security & Lockout Layer
- **Locked After Trial Expiry**: Once the 3 free trial rehearsals are completed or a 7-day tester code expires (`trialEndsAt <= now`), the app completely locks and displays the **Early Access Lockout Screen**.
- **Unbypassable**: Hardware back navigation is intercepted, and no dismiss gestures exist while locked.
- **Production Hardening**: Removed and disabled the dev "Simulate Purchase" button in production release builds so users/testers cannot bypass the paywall.
