# Changelog

All notable changes to the **Rehearse** project will be documented in this file.

## [1.0.0] - 2026-09-07 (Shipaton MVP)

### Added
- **Describe-Your-Situation Engine**: Prompt-to-scenario generator with counterpart stance and pushback patterns.
- **5 Archetype AI Counterparts**: The Defensive Boss, The Guilt-Tripper, The Hard Negotiator, The Passive-Aggressive Peer, The Micromanager.
- **Substance-Based Scoring Rubric**: 4-pillar evaluation (Ask Stated, Boundary Held, Specificity, Emotional Composure).
- **Executive Weakest-Line Rewrite**: Pinpoints hedged phrases and suggests masterclass alternatives.
- **Daily Practice Loop**: Framework of the Day (NVC, BATNA, STATE) and 1-turn Tricky Situation daily puzzle.
- **Strategic Message Coach**: Generates Direct, Diplomatic, and Boundary-Setting options for Slack/email threads.
- **Cross-Platform Expo Client**: React Native + Expo Web with calm executive coaching design system.
- **Subscription Architecture**: 5-day trial, $9/mo & $90/yr annual default tier with paywall enforcement.
- **Full-Stack VS Code Run & Debug**: F5 compound launch configuration.
